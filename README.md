# Pramada Shrestha — Portfolio

A personal portfolio website showcasing my projects and skills.

---

## Sections

- **Hero** — Introduction and CV

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone https://github.com/pramms19/Portfolio.git
cd Portfolio
```

2. Install dependencies

```bash
npm install
```

3. Create a `.env` file in the root directory

```env
RESEND_API_KEY=your_resend_api_key
EMAIL_FROM=onboarding@resend.dev
EMAIL_TO=pramadashrestha17@gmail.com
```

4. Run the development server

```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser

---

## Contact Form

The contact form uses [Resend](https://resend.com/) to send emails. To set it up:

1. Create a free account at [resend.com](https://resend.com)
2. Generate an API key
3. Add it to your `.env` file as `RESEND_API_KEY`
